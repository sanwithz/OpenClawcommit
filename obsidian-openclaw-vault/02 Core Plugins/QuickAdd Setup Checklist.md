# QuickAdd Setup Checklist

## Before You Start
- Install QuickAdd
- Install Templater
- Confirm template files exist in `90 Templates/`

## Create These QuickAdd Choices
1. Inbox Capture
2. Daily Note
3. Project Note
4. Weekly Review

## For Each Choice
- set destination folder
- set template file
- set filename rule
- optionally assign hotkey

## Recommendation
Start with Inbox Capture and Daily Note first, then add the others.
