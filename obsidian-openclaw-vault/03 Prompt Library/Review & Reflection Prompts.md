# Review & Reflection Prompts

## Weekly Review Prompt
```text
Using my recent daily notes, project notes, and unresolved inbox notes, draft a weekly review that is brief, accurate, and useful. Highlight wins, stalled work, open loops, and 1-3 priorities for next week.
```

## Reflection Prompt
```text
Search my recent notes and identify recurring patterns, useful lessons, and areas that need simplification or more attention.
```
