# NotebookLM Prompts

## Create summary from source set
```text
Using NotebookLM, summarize the currently selected notebook into: key ideas, decisions, open questions, and practical next actions. Then convert the result into an Obsidian research note.
```

## Source-grounded project brief
```text
Use NotebookLM to review the sources in this notebook and produce a concise project brief. Then save the brief into my Obsidian vault under the relevant Project or Resource note.
```

## Extract evergreen insight
```text
Ask NotebookLM for the strongest durable insights from the current notebook, then convert those into 1-3 evergreen notes in Obsidian.
```
