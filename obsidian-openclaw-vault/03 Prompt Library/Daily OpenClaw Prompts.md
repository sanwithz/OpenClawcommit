# Daily OpenClaw Prompts

## 1. Inbox Processing
```text
Review my Inbox notes in the Obsidian OpenClaw vault. Process them one by one using the vault rules. For each note, decide whether it should remain in Inbox, become a project update, become an area support note, become a resource/evergreen note, or be archived. Keep changes minimal and preserve meaning.
```

## 2. Daily Note Creation
```text
Create or update today’s daily note in the vault using the daily note template. Include focus, top priorities, tasks, notes, wins, blockers, and follow-up.
```

## 3. Project Review
```text
Review my active projects from the vault and give me a concise project status board: what is active, what is blocked, what is waiting, and what needs attention next.
```

## 4. Weekly Review Draft
```text
Generate a weekly review draft from recent daily notes, active project notes, and unresolved inbox items in the vault. Keep it concise, honest, and action-oriented.
```

## 5. Knowledge Synthesis
```text
Search my vault for notes related to the topic I name. Retrieve the smallest useful set of notes, then synthesize the main ideas, decisions, open questions, and next actions.
```
