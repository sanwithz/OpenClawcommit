# /search-vault-context

## Purpose
Retrieve the minimum useful vault context before answering or acting.

## Instructions
1. Start from the Central Dashboard or relevant hub note if the domain is broad.
2. Prefer canonical project, area, or resource notes.
3. Read recent daily/review notes only when status or timeline matters.
4. Avoid loading unrelated folders.
5. Return:
   - relevant notes
   - why they matter
   - concise synthesized context

## Goal
Use focused retrieval instead of bulk reading.
