# /review-project

## Purpose
Review one project note and produce a clear current-state update.

## Instructions
1. Read the main project note first.
2. Read related recent notes only if needed.
3. Summarize:
   - objective
   - current status
   - progress made
   - blockers
   - next actions
4. Update the project note if asked, preserving history and decisions.
5. Recommend related notes that should be linked or refreshed.

## Output
A concise project review with actionable next steps.
