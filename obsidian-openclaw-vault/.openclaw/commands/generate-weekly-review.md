# /generate-weekly-review

## Purpose
Generate a weekly review using daily notes, project notes, and recent updates.

## Instructions
1. Read recent daily notes for the target week.
2. Read active project notes selectively.
3. Identify:
   - completed work
   - important developments
   - stalled items
   - open loops
   - priorities for next week
4. Draft a weekly review note in concise structured form.
5. Link key project or resource notes where useful.
