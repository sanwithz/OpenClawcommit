# /process-note

## Purpose
Process a raw inbox or rough note into a clearer structured note.

## Instructions
1. Read the target note.
2. Identify whether it belongs in Inbox, Projects, Areas, or Resources.
3. Propose or apply:
   - cleaned title
   - correct note type
   - useful metadata
   - concise summary
   - related links
   - next action
4. If it is durable knowledge, convert or promote it into an evergreen/resource note.
5. Preserve original meaning; do not invent facts.

## Output
- summary of what changed
- target location
- recommended follow-up links
