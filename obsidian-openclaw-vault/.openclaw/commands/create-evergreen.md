# /create-evergreen

## Purpose
Turn raw notes, research, or reflections into a durable evergreen note.

## Instructions
1. Identify the core idea worth preserving.
2. Rewrite it into a clear, atomic note in your own words.
3. Add useful metadata.
4. Link related notes.
5. Place it under Resources unless another location is clearly better.

## Output
- final evergreen title
- summary of the idea
- related links
