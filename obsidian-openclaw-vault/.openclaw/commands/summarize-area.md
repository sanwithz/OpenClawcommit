# /summarize-area

## Purpose
Summarize the current state of an Area using its canonical area note and related materials.

## Instructions
1. Read the Area note first.
2. Load related project/resource notes selectively.
3. Summarize:
   - what this area covers
   - active concerns
   - linked projects
   - recent changes
   - maintenance needs
4. Suggest missing notes or outdated metadata if obvious.
