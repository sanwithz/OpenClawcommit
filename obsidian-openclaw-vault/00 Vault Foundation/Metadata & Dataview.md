# Metadata & Dataview

## Goal
Make notes easy to query, review, and summarize.

## Suggested Frontmatter
```yaml
---
type:
status:
created:
updated:
tags: []
area:
project:
source:
---
```

## Suggested Types
- daily
- literature
- evergreen
- project
- meeting
- prompt
- reference
- automation

## Dataview Use Cases
- show active projects
- list recent evergreen notes
- surface unprocessed inbox notes
- show this week’s reviews

## Principle
Only track metadata you will actually use.
