# Folder Structure

## Primary Structure
- `00 Vault Foundation/` — architecture, standards, metadata, templates overview
- `01 OpenClaw Integration/` — configuration, workflows, prompts, command strategy, context patterns
- `02 Core Plugins/` — notes about essential Obsidian plugins
- `03 Prompt Library/` — reusable prompts and slash-command patterns
- `04 Knowledge Workflows/` — capture, process, connect, project, research workflows
- `05 Automation/` — scripts, automations, tagging flows, maintenance helpers
- `06 Daily Systems/` — daily notes, reviews, task flows, habits, journaling
- `07 Advanced Techniques/` — multi-step reasoning, agentic workflows, cross-note analysis
- `08 Visualization/` — canvas, graphs, dashboards, knowledge maps
- `09 Maintenance & Optimization/` — cleanup, tuning, backups, context optimization
- `10 Community & Resources/` — references, best practices, examples
- `11 Evolution & Scaling/` — future system growth and collaboration models
- `90 Templates/` — reusable note templates
- `99 Attachments/` — images, PDFs, media, generated files

## Design Notes
- Numbered folders keep the vault predictable.
- Hubs/MOCs should point to working notes, not become dead directories.
- Keep heavy files in `99 Attachments/`.
