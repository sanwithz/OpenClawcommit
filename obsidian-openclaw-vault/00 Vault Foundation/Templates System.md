# Templates System

## Purpose
Templates reduce friction and make OpenClaw-assisted note creation more consistent.

## Recommended Templates
- Daily Note Template
- Literature Note Template
- Evergreen Note Template
- Project Note Template
- Research Note Template
- Meeting Note Template
- Prompt Template
- Automation Spec Template

## Template Principles
- Keep frontmatter lightweight
- Use repeatable sections
- Optimize for fast capture first, deeper refinement later
