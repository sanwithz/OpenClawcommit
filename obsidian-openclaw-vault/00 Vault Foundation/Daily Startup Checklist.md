# Daily Startup Checklist

## Goal
Start the vault the same way each day so work begins with clarity.

## Morning Startup
1. Open [[../08 Visualization/Central Dashboard|Central Dashboard]]
2. Check [[../08 Visualization/Task Boards|Task Boards]]
3. Review [[../08 Visualization/Active Work Board|Active Work Board]]
4. Open or create today’s daily note
5. Scan inbox notes
6. Identify top 3 priorities
7. Start with the highest-leverage task

## Midday Reset
1. Update daily note
2. Process any important new inbox captures
3. Review blocked or waiting projects

## End-of-Day Close
1. Update today’s daily note
2. Record wins, blockers, follow-up
3. Capture loose thoughts into Inbox
4. Leave clear next actions for tomorrow
