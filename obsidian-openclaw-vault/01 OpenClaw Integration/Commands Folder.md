# Commands Folder

## Purpose
A place to define reusable command patterns for OpenClaw-assisted work.

## Suggested Command Types
- inbox processing
- note cleanup
- daily review support
- literature note generation
- project status extraction
- vault maintenance checks

## Suggested Path
- `.openclaw/commands/` inside the vault, if you want vault-local command docs

## Rule
Commands should be short, reusable, and tied to a real workflow.
