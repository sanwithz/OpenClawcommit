# OpenClaw Command System

## Purpose
This vault includes reusable OpenClaw command notes under:

- `.openclaw/commands/`

## Included Commands
- `/process-note`
- `/review-project`
- `/summarize-area`
- `/generate-weekly-review`
- `/create-evergreen`
- `/search-vault-context`
- `/maintenance-check`
- `/daily-note`
- `/project-status-board`

## Design Rule
Commands should map to repeatable high-value tasks and encourage focused retrieval plus clean write-back.
