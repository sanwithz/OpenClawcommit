# Session Memory System

## Purpose
Define what should persist across sessions and what should stay temporary.

## Long-Term Memory
- enduring preferences
- stable workflows
- important project context
- recurring templates and standards

## Short-Term / Session Context
- current task state
- temporary references
- ad hoc brainstorming
- scratch analysis

## Principle
Promote durable insights into canonical notes; keep transient noise out of long-term knowledge.
