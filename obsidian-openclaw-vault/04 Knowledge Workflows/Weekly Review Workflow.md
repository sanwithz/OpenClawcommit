# Weekly Review Workflow

## Purpose
Turn weekly activity into clarity, decisions, and next priorities.

## Inputs
- Daily notes
- Active project notes
- Inbox notes still unresolved
- Recent resource or evergreen notes if relevant

## Steps
1. Open `08 Visualization/Reviews Dashboard.md`
2. Review daily notes from the week
3. Review active project notes
4. Review unresolved inbox items
5. Ask:
   - What moved forward?
   - What got stuck?
   - What created noise but little value?
   - What needs attention next week?
6. Create or update the weekly review note
7. Add 1-3 next-week priorities

## OpenClaw Support
Use:
- `/.openclaw/commands/generate-weekly-review`
- `/.openclaw/commands/project-status-board`
- `/.openclaw/commands/review-project`

## Output
A short weekly review note that improves decision quality.
