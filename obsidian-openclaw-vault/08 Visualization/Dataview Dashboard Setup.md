# Dataview Dashboard Setup

## Required Plugin
Install and enable **Dataview** in Obsidian community plugins.

## Recommended Plugin Stack
- Dataview
- Templater
- QuickAdd
- Periodic Notes

## Notes
- Dataview queries rely on frontmatter consistency.
- Keep `type`, `status`, `area`, and `project` maintained.
- Start simple; only add fields you actually use.
